# Task 2 — JSON-Driven Quest & Narration System

# Overview

- This System loads episode and chapter data from a JSON file, displays it in a UI, and allows users to simulate actions to complete chapters

# How To Run

- You’ll find the demo scene for this task here: Assets\Solutions\Task2_QuestNarration\Scenes\DemoScene.unity
- Hit Play, Display UI Canvase Shows Episode Cards And Chapters Inside cards Where you scroll Cards and Chapters inside Episode Cards.
- Press "SIMULATE ACTION" button Any chapter to Trigger and Complete chapter.

# Additional Features

- You can find EditorScene here: Assets\Solutions\Task2_QuestNarration\Scenes\EditorScene.unity
- Hit Play and In a scene, select the QuestEditor GameObject in the hierarchy.
- In the Inspector, where we Episodes data loaded and can be seen in the inspector.
- you can edit data and add more episode and chapters.
- Save the updated data using the Context Menu option "Save Episode Data"
